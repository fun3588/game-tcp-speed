## 🇨🇳 中文说明

- **测试环境**：Windows 11 x64
- **拦截方式**：用户态 Winsock API Hook (`connect` / `WSAConnect` 拦截并在 Socks5 协商后还原非阻塞状态)
- **转发链路**：AnyTLS + Reality TCP 隧道 (去除 Padding 填充)
- **目标游戏服**：`141.95.207.63`（登录端口: 1119，世界服端口: 8285）

### 1. 实测数据对比

| 测试指标 | 直连模式 (不加速) | AnyTLS 加速链路 | 变化 |
| :--- | :--- | :--- | :--- |
| **平均往返时间 (RTT)** | 577 ms | **245 ms** | 下降约 57% |
| **最差峰值延迟** | 1483 ms | **280 ms** | 重传毛刺明显减少 |
| **网络抖动 (Jitter)** | 344 ms | **15 ms** | 延迟波动大幅收敛 |
| **魔兽世界登录测试** | 频繁掉线 / 无法进入世界 | **正常登录进入世界服** | 认证与进入游戏均正常 |

### 2. 关键验证点

1. **界面与主线程响应**：
   - Hook 层在 Socks5 握手完成后恢复了套接字的原始非阻塞模式并补发事件通知，游戏主界面在握手期间没有发生假死或未响应现象。
2. **二进制握手包完整性**：
   - 去除 `padding_scheme` 填充后，魔兽世界原生 SRP 协议头（`WORLD OF WARCRAFT CONNECTION`）按原始字节长度传输，消除了之前进入世界服时弹出的“已断开连接”报错。
3. **v3.0 纯经典 Win32 API 架构与极低开销验证**：
   - 客户端采用纯经典 Win32 API + GDI 原生控件，单文件仅 174 KB，运行时常驻内存仅 3~5 MB（相比 WebView/WPF 降低 98% 以上），对正在运行的高负载 3D 游戏（如 WoW 11.2.5）实现真正的 0 掉帧、0 干扰；
   - 在游戏客户端处于运行中状态时进行注入，Hook 层通过主动拦截异步完成端口 `ConnectEx`，在玩家切换地图或重连世界服时自动接管连接，无需关闭游戏客户端；
   - 点击【一键卸载】后，远程线程调用 `FreeLibrary` 干净移除 Hook，游戏即刻无感恢复原生物理直连。
4. **游戏配置动态探测与真实物理直连测速**：
   - 客户端自动探测本地游戏安装目录（如 `E:\gamel\The War Within\WTF\Config.wtf`），解析出 `portal`（如 `EU`）并动态装载包含登录服（1119）、Firestorm 认证节点（141.95.207.63 / 51.75.148.169）及世界服（8285）的目标列表；
   - 全面测试针对上述端点执行原始物理网络连通与真实 RTT 测速，真实反映当前网络环境与骨干网状态。

## 🇺🇸 English Documentation

- **Environment**: Windows 11 x64
- **Interception Mechanism**: User-mode Winsock API Hook (`connect` / `WSAConnect` redirection with non-blocking socket state restoration)
- **Uplink Tunnel**: Clean AnyTLS + Reality TCP tunnel (without padding obfuscation)
- **Target Game Server**: `141.95.207.63` (Logon: 1119, World: 8285)

### 1. Benchmark Results

| Metric | Direct Connection | AnyTLS Accelerated | Difference |
| :--- | :--- | :--- | :--- |
| **Average RTT** | 577 ms | **245 ms** | ~57% reduction |
| **Max Peak Latency**| 1483 ms | **280 ms** | Retransmission spikes suppressed |
| **Jitter (StdDev)** | 344 ms | **15 ms** | Latency variance converged |
| **Logon Status** | Frequent Disconnects | **Normal Connection** | Successful logon and realm entry |

### 2. Key Verification Points

1. **Main-Thread Responsiveness**:
   - Preserving non-blocking socket modes and re-signaling events after Socks5 handshakes prevented UI lockups during connection establishment.
2. **Payload Integrity**:
   - Removing `padding_scheme` preserved authentic SRP handshake lengths, resolving the unexpected disconnection issues during realm transitions.
